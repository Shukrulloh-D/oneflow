## 📋 About Project

Учебное задание по фронтенд-разработке. Задача — сверстать макет из Figma: <a href="https://www.figma.com/design/DQ6F2KLrUiA3WjWL5OZ9FO/Portfolio-Creator--Copy-" target="_blank">Portfolio Creator</a>.

**Цель проекта:** отработать навыки вёрстки и работы с React — сборка компонентов, работа с состоянием (аккордеон, слайдеры, бургер-меню), адаптивная сетка, hover-эффекты и плавный скролл по якорям.

## 🛠 Стек технологий

- **React 18** — библиотека для построения интерфейсов
- **Vite** — сборщик и dev-сервер (быстрый запуск, HMR)
- **CSS** — обычные CSS-файлы рядом с компонентами, без препроцессоров
- **Google Fonts** — шрифт Inter

# Responsiveness

Desktop — two-column hero section (text + photo); "Smart contracts," "Believe your eyes," and "Seamless integrations" sections in two columns; six tabs in a row; platform features arranged in a checkerboard pattern; testimonial slider showing ~3.5 cards; resources section with a featured card + 3 cards in a row; "More from Oneflow" in 2 columns; footer with 4–5 columns of links.

Tablet — menu collapses into a hamburger icon;  Hero and two-column sections stack vertically (image below text) or the image scales down; client logos arrange into two rows; tabs scroll horizontally; platform features stack into a single column; testimonial slider displays two cards; resource cards arrange into two columns; footer columns form a three-column grid.

Mobile version: everything stacks vertically; headings scale down (the "Pressplay" heading scales to fit the screen width); client logos form a 2×3 grid or a scrolling ticker; tabs switch to horizontal scrolling or an accordion; testimonial slider supports swipe navigation; integrations grid has 3–4 columns; featured card displays the image above the text; resource cards and "More from Oneflow" stack into a single column; footer link columns switch to an accordion or a two-column grid; subscription form stacks the input field and button vertically; buttons span the full width.

# Interactivity

Burger menu on tablets and mobile; dropdown submenus in the desktop header; fixed header with background color change on scroll; smooth scrolling for anchor links; tab switching in the features section (animated text and image transition); video playback in the "Pressplay" section; testimonial slider with arrow buttons/pagination and swipe support; hover states for buttons, links, testimonial cards, resource cards, and integration logos; subtle entrance animations for sections on scroll (to be confirmed); email field validation in the subscription form;  "Try for free" / "Book a demo" buttons — link to the sign-up/booking form (to be confirmed).

# Design

Modern, "warm" SaaS style: alternating sections of pastel pink, dark teal, and white; yellow accents on primary buttons; staged surrealist photos and 3D objects in pastel tones (an armchair with clouds, a hand holding a hoop, a VR scene, a hand with a rainbow wave); geometric sans-serif typography (font to be confirmed via the mockup), very large bold headings—especially the giant "Pressplay" headline; rounded corners on cards and buttons; product interface illustrations featuring cards and charts; round dark icons for features; consistent structure for testimonial, resource, and "More from Oneflow" cards.
